Uso Administrativo

Use quando alguém confirmar por mensagem o item que vai levar, mesmo que a lista pública esteja fechada. A pessoa será registrada no item escolhido e aparecerá na lista pública.

A contribuição manual não marca o item como entregue. Use o botão “Marcar entregue” somente quando receber fisicamente.

Itens e responsáveis

Use “Editar Item” para alterar dados do item, “Marcar entregue” para registrar o recebimento físico e “Tirar pessoa do item” para remover uma contribuição.
